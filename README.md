# Car Wash Management System 🚗💦

A desktop application built for managing car wash services, customer details, and daily operations efficiently.

## 🛠️ Technologies Used
* **Language:** C#
* **Framework:** .NET Windows Forms
* **Database:** SQLite / Local Database

## ✨ Features
* **Dashboard:** Easy-to-use interface to track operations and management.
* **Customer Management:** Store and manage customer names, phone numbers, and records.
* **Service Tracking:** Handle categories, pricing, and car wash service bookings.

## 🚀 How to Run
1. Clone or download this repository to your local machine.
2. Open the solution file (`WindowsForms.slnx`) in **Visual Studio**.
3. Run the project by clicking the **Start** button.
